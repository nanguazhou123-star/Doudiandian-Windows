# 豆点点 Windows 使用说明

官方下载：[Microsoft Store](https://apps.microsoft.com/detail/9NLJH5HG9L5V) · [itch.io 完整便携版](https://heykim.itch.io/doudiandian)

[返回英文首页](../README.md)

豆点点（Doudiandian）是一款 Windows 离线拼豆图纸工具，可以把 JPG、PNG 转成可编辑图纸，修改单颗豆子，统计各色用量，并导出 PNG 或 A4 PNG 分页。本说明对应 Windows 1.0.3 便携版，由开发者维护。itch.io 的开发者名称为 HeyKim，Microsoft Store 中为 DaMiZhou Studio。

本仓库仅提供产品文档、教程和反馈入口，不提供桌面应用源码。安装包请从上方官方下载渠道获取。

## 1. 下载与打开

需要 Windows 10 或 Windows 11，64 位 x64 系统。软件无需注册应用账号，图片处理和作品保存均在本机完成。

1. 在 itch.io 产品页下载完整的 `Doudiandian-1.0.3-Windows-x64.zip`。
2. 选择“全部解压”，打开解压后的文件夹，运行 `Doudiandian.exe`。
3. 保留同目录的 DLL、`resources`、`locales` 等配套文件，不要只移动 EXE。运行不需要 Node.js 或开发工具。
4. 界面会根据系统语言选择中文或英文，也可以在语言设置中手动选择并记住偏好。

itch.io 完整功能免费下载，可以跳过建议的 US$3.99 自愿支持。支持用于开发，不解锁额外功能，也不增加软件或素材授权。便携版 EXE 未签名，Windows 可能提示发布者信息；使用前请阅读包内说明和相关声明。

## 2. 导入图片，选择尺寸与色数

一次导入一张 JPG 或 PNG，文件不超过 10 MB，单边不超过 6,000 像素。先选主体清楚、背景简单的图片；复杂照片缩成小格子后可能丢失细节，需要手动修改。

格子尺寸支持每边 8–100 格，转换预设支持 2–30 色。尺寸决定可用位置数量，色数决定颜色简化程度，两者都不等于实际用珠总量。可以比较不同色数下的轮廓、阴影和零碎色块，也可以尝试“清晰轮廓”。

选择完整图片并留边，适合保留整个主体；选择裁剪填满时，请检查花瓣等边缘是否被裁掉。透明 PNG 的透明区域会保留为空格，不透明的白底或其他背景会成为图案的一部分。软件没有自动去背景或批量转换功能。

## 3. 修改图纸并核对用量

进入编辑页后可以放大查看，用画笔重涂单格、橡皮清空位置、连通填充修改区域、取色器选择已有颜色；操作可撤销、重做。各色数量会随编辑更新。

公开向日葵实例的初始结果为 50 × 50 格、16 色、836 颗。50 × 50 是 2,500 个可用位置，透明空格不放豆，所以实际用量为 836 颗。

将第 25 列、第 26 行的一颗 A26 改为 M3 后：

| 状态 | 使用颜色数 | 总用珠量 | A26 | M3 |
| --- | ---: | ---: | ---: | ---: |
| 修改前 | 16 | 836 | 238 | 0 |
| 修改后 | 17 | 836 | 237 | 1 |

这里只替换颜色，没有增删占用位置，因此总量不变；M3 首次出现，颜色数增加为 17。手动编辑后的色数可能超过转换预设，请以最后的用量清单为准。

[查看实际导出的向日葵 PNG](https://img.itch.zone/aW1nLzMxMjQzMjUyLnBuZw==/original/lUNOG8.png)

也可以从 60 张内置原创图纸开始修改、在空白格子上画图，或使用三种内置字体生成短文字图案。文字支持最多 20 个字符，换行也计入字符数。

## 4. 先保存作品，再导出图纸

需要继续修改时，先保存到本机“我的作品”，之后从作品列表重新打开。本机最多保存 50 个可编辑作品，当前没有作品文件导入导出或云同步。

制作时可以导出带色号的网格图或豆子效果 PNG，并选择附上颜色与数量清单。导出后请打开图片检查文字和图案是否清楚。PNG 保存的是图纸图像，不是完整的可编辑作品备份。

## 5. A4 PNG 与实物颜色

软件可以生成 A4 PNG 分页；没有 PDF 导出，也不直接控制打印机。在外部图片或打印软件中选择“实际大小 / 100%”，关闭“适应页面”，先用尺核对纸面标注尺寸，再使用豆板。已有数字图纸不代表纸张和豆板已完成实测匹配。

色表采用 221 个 MARD 社区屏幕参考色，不是官方实物校色，也不保证与你手中的豆子完全一致。开做前请对照自己的材料确认；当前没有库存管理或缺豆提醒。
