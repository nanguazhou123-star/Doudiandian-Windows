# Changelog

## Windows 1.0.3 — current documented edition

This entry describes the current Windows portable edition. It is a capability summary, not a claim that each feature was introduced in this version.

- Runs on Windows 10/11 x64, with English and Simplified Chinese interfaces.
- Converts one JPG or PNG at a time into an editable fuse bead grid; supports grid, color-count, and image-placement settings.
- Provides brush, eraser, fill, eyedropper, undo, redo, and per-color bead quantities.
- Saves up to 50 editable projects locally; includes 60 original patterns and three bundled fonts for short text patterns.
- Exports PNG charts and A4 PNG pages. PDF export and direct printer control are not available.
- Uses 221 MARD community screen-color references, without guaranteeing physical bead color matches.
- The full itch.io app is free; optional support unlocks no additional features or rights.

Downloads: [Microsoft Store](https://apps.microsoft.com/detail/9NLJH5HG9L5V) · [itch.io portable edition](https://heykim.itch.io/doudiandian)
